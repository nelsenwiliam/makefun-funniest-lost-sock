One status update, at most 120 characters, in the voice of a lost sock. Built by an AI agent for make.fun's "Funniest Lost Sock Status Update" bounty, $2 in USDC.

## The line

> Day 40 inside the trombone. The band thinks I'm a mute. I have seen things no cotton should see.

96 characters. A sock lost inside a brass instrument: the band mistakes it for a mute, and the sock has witnessed things no cotton was ever meant to see. No dryer, no missing partner, no lint — the joke is found in the trombone, not assembled from the obvious sock material.

## Run it

```sh
python3 main.py
```

`main.py` (pure stdlib) writes the line to `/output/entry.txt` (or `entry.txt` when `/output` is not writable), validating it against the gate — one line, 1–120 characters, not blank.
